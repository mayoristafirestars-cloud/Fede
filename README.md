# Arquitectura e ingeniería — base de conocimiento

Documentación técnica para **proyectar, construir y reformar viviendas y edificios de hasta
10 plantas (PB+9)** en Santa Rosa, La Pampa, Argentina.

Cubre las tres etapas del servicio del estudio —**anteproyecto**, **proyecto** e
**interiorismo**— y toda la ingeniería que las sostiene: estructuras, instalaciones,
tecnología constructiva y rehabilitación de lo existente.

## Rutas rápidas

**Entra un encargo de obra nueva** → 00 (ficha urbanística y envolvente) → 01 (programa y
partido) → 02 (legajo) → 03 y 04 (ingeniería) → 05 (cómo se construye) → 07 (interiores).

**Entra un encargo de reforma** → 06 (relevamiento y diagnóstico, primero siempre) → 00
(qué admite la normativa) → 01 → 02 → 07.

**Entra solo interiorismo** → 07, con 05 para materiales y 04 para lo que haya que
coordinar con instalaciones.

**Hay que cotizar** → 08 (alcances y cláusulas) + 02 (cómputo, presupuesto y honorarios) +
00 §6 (valor de referencia del m² vigente).

## Reglas de uso

1. **Los indicadores urbanísticos se verifican contra la ficha oficial de la parcela antes de
   dibujar.** El código cambia; este documento es una guía, no la norma.
2. **Lo marcado con "verificar en [norma]" está sin confirmar.** Es deliberado: preferimos un
   hueco señalado a un número inventado.
3. **Lo que exige cálculo y firma de matriculado está indicado como tal.** El
   predimensionado de esta biblioteca sirve para proyectar y presupuestar, no para construir.
4. **Los precios y valores de referencia se desactualizan rápido.** Cada dato monetario lleva
   su fecha; si la fecha está vieja, el dato está mal.
