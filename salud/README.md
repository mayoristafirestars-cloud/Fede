## Cómo usar

Invocá al agente que corresponda:
- `@medico` para temas clínicos, estudios, medicación
- `@nutricionista` para armar/ajustar dieta
- `@entrenador-fisico` para rutinas de fuerza
- `@psicologo` para hábitos, ánimo, motivación, estrés

Antes de recomendar algo, cada agente lee los archivos relevantes y consulta
lo que dijeron los otros para no pisarse.
