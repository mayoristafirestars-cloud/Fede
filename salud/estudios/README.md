# Estudios médicos

Guardar acá análisis de sangre, ecografías, rayos X, etc.

Nombrar archivos así: `YYYY-MM-DD_tipo.md` o `YYYY-MM-DD_tipo.pdf`
Ejemplos:
- `2026-04-17_analisis-sangre.md`
- `2026-04-17_ecografia-abdominal.pdf`

Para cada análisis, el @medico debe:
1. Leer valores y compararlos con los previos
2. Marcar los que están fuera de rango
3. Resumir en `bitacora.md` lo más importante
4. Si algo requiere acción urgente, agregarlo a `agenda.md`
