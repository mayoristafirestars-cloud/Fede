Mate 0.5

Programar agentes en castellano, sin que la IA te invente precios

Mate es un lenguaje de programación chico, con palabras en castellano.

Sirve para armar agentes: partes del programa que reciben mensajes, consultan a una IA y contestan.

Vos escribís las reglas, y Mate revisa cada respuesta de la IA antes de que salga.

Bajarlo e instalarlo Ver el curso

Para quién es

  • Para quien tiene un negocio, usa Windows y quiere probar un agente que atienda consultas con su lista de precios, sin aprender inglés técnico.
  • Para quien nunca programó y quiere empezar por algo que se lee como se habla: si, para, mostrar, preguntar.
  • Para quien ya programa y quiere ver una idea: que los límites de la IA se escriban en el programa y los controle el lenguaje, no la IA.

Se escribe con el Bloc de notas y se corre desde PowerShell. Lo único que hay que tener instalado es Python.

Un mostrador con IA, entero

Este programa es completo: se puede copiar, guardar como mostrador.mate y correr. Los precios son de muestra.

mensaje Consulta { pregunta: texto }

agente Mostrador {
    estado permitidos = [3500, 1250, 950]

    frenos {
        precios: permitidos
        prohibido: ["descuento", "fiado"]
        reserva: "Eso te lo confirma una persona. Ya te paso."
        consultas_por_dia: 100
    }

    al recibir Consulta como c {
        responder consultar_ia(
            "Atendés un almacén. Yerba $ 3.500, azúcar $ 1.250, fideos $ 950.",
            c.pregunta, "La yerba sale $ 3.500.")
    }
}

mostrar(preguntar Consulta { pregunta: "¿Cuánto sale la yerba?" } a Mostrador)

prueba "un precio inventado no le llega al cliente" {
    simular_ia("El café sale $ 9.000.")
    sea dicho = preguntar Consulta { pregunta: "¿Y el café?" } a Mostrador
    asegurar dicho == "Eso te lo confirma una persona. Ya te paso."
}

Si la IA nombra un precio que no está entre los permitidos, o promete un descuento, Mate no deja pasar esa respuesta: le pide otra y, si vuelve a estar mal, contesta con el texto de reserva. La prueba de abajo lo comprueba sin gastar un peso, porque en las pruebas la IA es simulada.

# ensayarlo sin clave, sin internet y sin gastar
mate correr mostrador.mate --ia-simulada
# correr sus pruebas
mate probar mostrador.mate

Las cuatro cosas que lo diferencian

1Se lee en castellano

Las palabras del lenguaje, la ayuda y los errores están en castellano. Un error dice el archivo, el renglón y qué pasó, y muchas veces sugiere el arreglo.

2Mensajes con contrato

Cada mensaje declara qué datos lleva y de qué tipo. Un pedido mal armado se avisa antes de correr el programa, no cuando ya le llegó a un cliente.

3Frenos

Precios permitidos, palabras prohibidas, largo máximo y tope de consultas por día. Los escribís vos, y los controla Mate en cada respuesta de la IA.

4Aprende de las correcciones

Cuando el agente contesta mal, le anotás una lección desde PowerShell, sin tocar el programa. Mate también propone lecciones, y no las usa hasta que las aprobás.

Cómo bajarlo e instalarlo

En Windows 10 u 11, sin permisos de administrador:

  1. Instalá Python desde python.org/downloads. En la primera pantalla del instalador, abajo, marcá la casilla Add python.exe to PATH antes de tocar "Install Now".
  2. Bajá Mate como archivo ZIP, hacé clic derecho sobre el archivo y elegí "Extraer todo".
    Bajar el ZIP
    Ojo: ese ZIP trae el proyecto entero, con otras carpetas que no son de Mate. La única que hace falta es la carpeta mate.
    Mate todavía no tiene una dirección de internet para bajarlo: pedile a quien te pasó esta página el archivo ZIP con la carpeta mate.
  3. Instalá la orden mate: entrá a la carpeta mate y hacé doble clic en el instalar.bat que está ahí adentro. (Si afuera de la carpeta mate ves otro instalar.bat, ese no es: es de otro programa.) Dice qué hizo y cómo deshacerlo. Si Windows muestra un cartel azul, elegí "Más información" y después "Ejecutar de todas formas".
  4. Probalo: abrí PowerShell y escribí:
mate --version
mate curso

El instalador escribe un solo archivo en tu usuario y no toca nada más. Si no anda en tu computadora, Mate se usa igual con la orden larga, parado en la carpeta que contiene a mate: python mate\mate.py curso.

El curso

Doce clases cortas, de "hola" a un mostrador con IA, lista de precios, frenos y lecciones. Cada una trae el programa completo, el comando para correrlo, lo que tiene que salir, el error más común y un ejercicio resuelto. Ninguna necesita clave ni internet.

Viene dentro de Mate, en la carpeta mate\curso. Para verlo: mate curso, y para leer la primera clase: mate curso 1.

Para qué no sirve todavía

  • No atiende por WhatsApp ni por una página web. Hoy la charla con el agente es por teclado, en la ventana de PowerShell.
  • Es un proyecto nuevo, hecho por una sola persona. No hay comunidad ni soporte. Lo que hay para aprender es el curso, los ejemplos y la ayuda que trae adentro.
  • Es lento y chico al lado de Python o JavaScript. Está pensado para programas cortos y claros, no para sistemas grandes.
  • Los frenos no entienden lo que leen. Buscan importes, palabras y cuentan letras. Atajan lo más común; no son una garantía absoluta.
  • La IA no puede decir totales ni sumas. El freno de precios deja pasar solo los importes de tu lista: si un cliente pregunta cuánto salen 3, la respuesta con el total se reemplaza por "eso te lo confirma una persona", salvo que el programa calcule esos totales y los sume a los precios permitidos.
  • La IA de verdad es paga (se le paga a Anthropic, por consulta) y cada consulta es suelta: la IA no recuerda la pregunta anterior.
  • Dos partes todavía no se probaron en condiciones reales: la conexión con la IA de verdad y el instalador de Windows. Todo lo demás tiene pruebas automáticas, y todo se puede ensayar sin gastar.

Mate es un solo archivo de Python, sin nada más que instalar. Lo que hace un programa de Mate se puede hacer en Python con más trabajo: la ventaja es que acá los contratos, los frenos y las lecciones ya vienen hechos y se escriben en castellano.
